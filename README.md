## 🎯 What is this?

A collection of training material for people learning DevOps: course notes, slides and practical exercises, published as a website and kept open for anyone to read, fork and reuse.

> 💡 Useful for self-learners, trainers preparing a DevOps course, and teams onboarding new engineers.

## 🚀 How to Use It

1. **Browse online:** open 👉 [hclpandv.github.io/devops-training-material](https://hclpandv.github.io/devops-training-material/)
2. **Follow the path:** start with the [hands-on path](devops-hands-on-path.md) if you want a guided order.
3. **Practice:** try each exercise on your own machine, a VM or a cloud sandbox. Reading alone won't make it stick.
4. **Pick a topic:** each folder above works on its own if you only need one skill.

### Suggested order for beginners

```
Linux → Git → Docker → Kubernetes → Terraform → Ansible
```

Add `network/` early if networking is new to you, and `vagrant/` if you want local VMs to practice on.
